# Other resources worth your time

This repo is deliberately narrow — one file, focused on 2026 system design. For everything else:

**DSA practice** — go straight to the source. LeetCode's own judge and test cases beat any homegrown or curated-list alternative:
- [NeetCode](https://neetcode.io/) — pattern-based practice with real explanations, not just a link list.
- [yangshun/tech-interview-handbook](https://github.com/yangshun/tech-interview-handbook) — comprehensive, well-curated, includes solid coding-interview and behavioral material in one place.
- [kdn251/interviews](https://github.com/kdn251/interviews) — long-standing, widely trusted (30k+ stars), covers core data structures and algorithms with video walkthroughs.

**Behavioral prep** — [yangshun/tech-interview-handbook](https://github.com/yangshun/tech-interview-handbook) above covers this well; pair it with your target company's actual leadership/competency framework (e.g., Amazon's Leadership Principles) rather than a generic question bank, since senior behavioral loops grade against that framework specifically.

**System design, for more depth than this repo's 19 prompts:**
- [ashishps1/awesome-system-design-resources](https://github.com/ashishps1/awesome-system-design-resources) — the most actively maintained curated system design list on GitHub, organized by topic.
- [donnemartin/system-design-primer](https://github.com/donnemartin/system-design-primer) — still the best starting point for the fundamentals (scaling, replication, caching) in plain English. Treat it as the foundation this repo's AI-production and 2026-rubric content builds on top of.

If you find something better or more current, open a PR.
